# 🧠 Python & Django Quiz Portal App

A full-stack web application designed to create, manage, and take interactive quizzes. Built using **Python and Django**, this project focuses on handling dynamic question-and-answer workflows, tracking user scores, and managing relational database models.

---

## ✨ Key Features

* **User Authentication & Profiles:** Secure registration and login system ensuring each user has a dedicated account to track their quiz attempts and performance history.
* **Quiz Management:** Admins or creators can add categories, set up quizzes, and define multiple-choice questions with correct answers.
* **Interactive Quiz Taking:** Users can select quizzes, answer questions dynamically, and submit their responses for evaluation.
* **Score Tracking & Results:** Instant grading upon submission, showing users their total score, correct answers, and performance breakdown.

---

## 🛠️ Tech Stack

* **Backend:** Python, Django (MVT Architecture)
* **Database:** SQLite (Default Django DB)
* **Frontend:** HTML5, CSS3, Bootstrap (for responsive interfaces and clean quiz cards)
* **Authentication:** Django Built-in Auth & Session Management
